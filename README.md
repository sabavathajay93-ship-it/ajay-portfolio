# 💻 Ajay's Developer Portfolio

Welcome to my personal developer portfolio! This website showcases my technical skills, academic experience, interests, and development journey in web development, software development, and data analytics.

## 🌟 About the Project

This portfolio website is designed to introduce me, highlight my technical knowledge, and provide visitors with access to my resume, projects, and contact information.

The website features a dark-themed interface with purple accents, a navigation menu, an introduction section, and a work experience timeline.

## 🚀 Features

- **Personal Introduction:** A welcoming homepage introducing Ajay.
- **Responsive Layout Foundation:** Flexbox-based sections for organizing portfolio content.
- **Navigation Menu:** Links to Home, About, Projects, and Contact pages.
- **Download Resume:** A button to download my resume PDF.
- **GitHub Profile:** A button to visit my GitHub profile.
- **Typing Animation:** Animated text displaying Web Developer, Data Analyst, and Software Developer.
- **Work Experience Timeline:** Highlights my academic learning and technical development.
- **Custom Dark Theme:** A dark background with purple accents and white text.
- **Google Fonts:** Uses Google Sans for typography.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layout, colors, and typography.
- **JavaScript** — Interactive typing animation.
- **Typed.js** — Animated text effect.
- **Google Fonts** — Google Sans typography.
